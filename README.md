# 🎓 Student Management System

A Java Swing-based Student Management System developed as part of my Software Engineering coursework.

This desktop application provides a user-friendly graphical interface to manage student information, academic records, GPA calculations, reports, and industry training eligibility.

## ✨ Key Features

* 👨‍🎓 Student Registration and Management

  * Add new students
  * Update student information
  * Search and view student details

* 📚 Batch and Academic Management

  * Manage student batches
  * Record and manage academic marks

* 📊 Academic Report Management

  * View student academic information
  * Generate academic reports

* 🧮 GPA Calculation

  * Calculate student GPA based on academic performance

* 🆔 Automatic Registration Number Generation

  * Generate unique student registration numbers

* 🎓 Industry Training Eligibility

  * Check eligibility based on academic requirements
